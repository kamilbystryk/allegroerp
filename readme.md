beeErp

beeErp to wewnętrzny system ERP wykorzystywany przez Bee Electronics do zarządzania sprzedażą, zamówieniami, magazynem i produkcją.

Integracja z Allegro

Aplikacja korzysta z Allegro REST API w celu:

Pobierania zamówień klientów.

Aktualizowania statusów realizacji zamówień.

Obsługi komunikacji z kupującymi.

Dostęp do konta Allegro odbywa się poprzez OAuth2. Aplikacja jest wykorzystywana wyłącznie wewnętrznie i nie jest oferowana innym sprzedawcom.
